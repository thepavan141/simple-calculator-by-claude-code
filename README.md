# 🧮 Simple Calculator by Claude Code

A sleek, responsive, and modern web-based calculator built for speed and simplicity. This project demonstrates a clean separation of concerns between structure (HTML), style (CSS), and logic (JavaScript).

## ✨ Features
- **Instant Calculations:** Performs arithmetic operations (+, -, ×, ÷) instantly using client-side logic.
- **Responsive Design:** Adapts perfectly to desktops, tablets, and mobile screens.
- **Modern UI:** Features a clean, high-contrast aesthetic with smooth hover effects and active states.
- **Error Handling:** Gracefully handles invalid inputs and division by zero.

## 🛠️ Tech Stack
- **HTML5:** Semantic structure for the interface.
- **CSS3:** Custom styling with CSS Variables (root variables) for easy theme management.
- **JavaScript (ES6+):** Pure Vanilla JS for all mathematical logic—no external libraries required.

## 🚀 Getting Started
Since this is a pure frontend project, there is **no installation required**.

### Option 1: Local View
1. Download the project folder.
2. Open `index.html` in any web browser.

### Option 2: VS Code Live Server (Recommended)
1. Open the project folder in VS Code.
2. Install the **Live Server** extension.
3. Click **"Go Live"** at the bottom right of the window.

## 🏗️ Project Structure
- `index.html`: The main entry point and UI structure.
- `static/style.css`: Contains the design system and layout styles.
- `static/script.js`: Contains the calculation engine and DOM manipulation logic.
